# Mario Games

A Mario fan game made with Python and pygame, in a Game Boy style.

## Run it

1. Install Python 3.
2. Install pygame:
   ```
   pip install pygame
   ```
3. Start the game:
   ```
   python main.py
   ```

## Controls

| Key | Action |
| --- | --- |
| Arrow keys | Move / pick menu options |
| Space or Up | Jump |
| Z or Shift | Run |
| Enter | Select |
| P or Esc | Pause |

## Play in a browser

Build the web version with [pygbag](https://pypi.org/project/pygbag/):

```
pip install pygbag
pygbag .
```

Then open http://localhost:8000.
